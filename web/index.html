照片留在自己的硬碟

Photo Sync 把 iPhone 相簿的原始檔, 走同一個區域網路傳到你自己的電腦. 沒有雲端, 沒有帳號, 沒有中繼伺服器.

iOS 18+ macOS 14+ Windows 11 22H2+ LAN only SHA-256 verified
目錄 這是什麼 取得程式 安裝設定 10 步 日常使用 檔案落點 自動同步 同步後刪除 疑難排解 延伸資料

這是什麼

你在 iPhone 上挑幾個相簿, 在電腦上挑一個資料夾. 之後每次同步, App 只把還沒備份過的原始資源送過去. 傳輸只走同一個區域網路 (LAN), 不經 AirDrop, 不經藍牙, 不經任何 Internet relay.

  • 原始檔, 不是壓縮副本. PhotoKit 給什麼就傳什麼, 含 RAW, 影片, Live Photo components 與 adjustment data.
  • 只新增, 永不覆寫. iPhone 上刪掉的東西不會傳播到電腦, 電腦上已存在的檔案也不會被蓋掉.
  • 每個檔案驗過 SHA-256 才落地. 中途斷線從 checkpoint 續傳, 不會從頭重來.
  • 只在 iCloud, 不在本機的照片會被跳過. App 固定不觸發 iCloud 下載, 需要的話請先在 Photos 下載到 iPhone.
  • 配對一次就好. 電腦顯示六位數字, 這組數字不走網路, 只用來確認是這台.

安裝設定 10 步

從零到第一次同步完成. 步驟有先後: 電腦端先備妥 destination 與配對碼, iPhone 才有東西可以連.

  1. 前置

    確認兩端在同一個網路

    iPhone 必須走 Wi-Fi; 電腦可以是 Wi-Fi 或 Ethernet, 只要在同一個 LAN. Guest network, VLAN 隔離, VPN 或 router 的 client isolation 會擋掉 Bonjour discovery, App 不會繞過這些限制.

  2. 電腦

    啟動 receiver

    Mac 端啟動後不會有 Dock 圖示, 只在 menu bar 出現一個小圖示; 點開選 Open Setup. Windows 端同樣是常駐 tray 圖示.

  3. 電腦

    選一個目的地資料夾

    按 Choose Destination, 第一次會開在 Downloads. 實際寫入位置固定在 <你選的資料夾>/iPhoneSync/ 之下, 這層容器不可更改. 選到 symbolic link 時會先解析成實際 target 再保存權限.

  4. 電腦

    選 Storage Mode

    決定 iPhoneSync/ 裡面怎麼分層, 三種版面見下面的表. 之後改模式不會搬動或刪除已經傳好的檔案.

  5. 電腦

    按 Pair iPhone, 拿到六位數字

    畫面顯示六位數配對碼與兩分鐘倒數, 過期就重按一次. macOS 15 以上首次會跳出 Local Network 授權提示, 必須允許, 否則 iPhone 看不到這台.

  6. iPhone

    授予 Photos Full Access

    首次啟動 App 時給予完整照片存取權. Limited (只選部分照片) 不被接受, 因為 App 需要讀取整個相簿的資源清單才能算出哪些還沒備份.

  7. iPhone

    Choose Albums 挑相簿

    可以複選. 每個相簿在電腦端會有自己的資料夾; 兩個同名相簿不會被合併, 第二個會穩定地變成 名稱 (2).

  8. iPhone

    Find Mac, 輸入六位數字

    首次會跳出 Local Network 授權提示, 必須允許. 從候選清單挑你的電腦, 輸入畫面上顯示的六位數. 配對成功後導出的 secret 存進 Keychain, 之後同步不再需要輸入任何東西.

  9. iPhone

    按 Sync Now

    第一次會傳最久. 傳輸中 iPhone 不會自動鎖定; 完成後 LAST SYNC 會給你四個數字: Added (這次新增), Already (先前已備份), Not local (只在 iCloud 被跳過), Failed.

  10. 選用

    打開自動同步或一鍵觸發

    不想每次記得開 App: 打開 Automatic Sync. 想要一鍵: 到控制中心加入 Sync Now 控制項, 或用 Siri 說 Sync now in Photo Sync. 確定要在備份後清 iPhone 空間, 再讀完下面的警告後打開 Delete After Sync.

日常使用

電腦保持開機登入就好, receiver 會自己恢復目的地, 配對與 manifest. iPhone 端有四種觸發入口, 全部走同一條同步路徑, 同一時間只允許一個 run.

入口位置行為
Sync NowApp 主畫面的電腦卡片立即前景同步, 永遠可用的 fallback
控制中心控制項控制中心自訂項目不開啟 App 直接觸發
Shortcuts / SiriSync now in Photo Sync同上, 走同一條路徑
Automatic Sync主畫面 AUTOMATIC SYNC 區opt-in 後由 iOS best-effort 啟動

重跑一次只補新的. 第二次同步的摘要通常長這樣:

0Added 這次新增
812Already 已備份
3Not local 只在 iCloud
0Failed 失敗

同步中按側邊鍵鎖定或切到別的 App, iOS 會停掉這次前景 run. App 會先安全關閉連線, 下一次同步從 checkpoint 接續, 已傳完的位元組不會重傳. 兩端各自的 Operation Log 保留最新 500 筆事件, 是事後回查的依據.

檔案落點

容器固定是 iPhoneSync, 裡面的版面由 Storage Mode 決定.

模式實際路徑適用
Album / Year / Month
預設		<destination>/iPhoneSync/<album>/<year>/<month>/相簿多, 時間跨度長
Album<destination>/iPhoneSync/<album>/相簿本身即是分類
Single Folder<destination>/iPhoneSync/之後交給其他工具再分類

已存在的資料夾會直接重用並保留全部內容. 目的地若有同名檔案, 或 symbolic link 解析不到資料夾, 該筆會被拒絕並記在 Operation Log.

自動同步的真實語意

Automatic Sync 是 opt-in 且 best-effort 的, 不是 cron. 打開之後實際會發生什麼, 值得先講清楚:

  • 每 30 分鐘嘗試一次. 沒有指定時間, 沒有每日配額; 成功與失敗都以同樣的間隔重新排下一次.
  • 不要求充電. 電池供電時 iOS 一樣可能啟動, App 不讀取電池狀態.
  • 不保證準時, 也不保證會執行. 這一切都只是給 iOS 的建議時間, 實際可能晚很多, 或整晚都不跑.
  • 單次執行不設時間上限. iOS 給多久就傳多久, 被系統中止時未傳完的部分由 checkpoint 續傳.
  • 不會有兩條連線. 上一次還在跑時, 下一次啟動直接略過並重排.

所以 Sync Now 永遠是那個確定會動的按鈕. 自動同步從來沒跑過時, 先確認系統設定裡的 Background App Refresh 沒被關掉.

同步後刪除 (選用, 預設關閉)

Delete After Sync 讓 App 在備份確認完成後, 幫你清掉 iPhone 上的來源照片. 這是唯一會刪東西的功能, 所以邊界寫得很死.

刪除是整個照片圖庫層級的, 不是只移出所選相簿. 如果你使用 iCloud Photos, 刪除也會同步影響同一個 Apple Account 的其他裝置. 電腦上已經傳好的檔案永遠保留, 不受影響.

  • 單位是整張照片. 一張照片的每一個本機原始資源都被電腦確認收妥, 才有資格被刪; 只要有一個是 Not local, 失敗或被取消, 整張都保留.
  • 永遠有系統確認. 前景同步完成後由 iOS 跳出 Photos 的刪除確認, 你按取消就不刪.
  • 背景同步不會偷偷刪. 背景 run 只會排一份待確認清單, 發一則只講數量的通知; 回到 App 按 Delete N Synced Photos 才會真的刪.
  • 關掉就清空. 關閉開關或按 Forget 時, 待刪清單一併清除.

疑難排解

症狀檢查點
Find Mac 找不到電腦兩端同一 Wi-Fi; 電腦的配對視窗還在兩分鐘內; 不是 guest network / VLAN / VPN; router 沒開 client isolation
配對碼輸入失敗碼已逾時 (120 秒) 或嘗試次數用盡, 回電腦重按 Pair iPhone
大量 Not local那些資源只在 iCloud. App 固定不下載, 請先在 Photos 把它們下載到 iPhone
自動同步從來沒跑過先確認 Background App Refresh 可用; 這本來就不保證執行, 用 Sync Now 當 fallback
顯示已同步但沒刪除背景 run 只建立待確認清單. 回到 App, 在 AFTER SYNC 按 Delete N Synced Photos
電腦端寫入被拒目的地有同名檔案, 或 symlink 解析不到資料夾. Operation Log 會標示, 換一個目的地或移除該項目
Mac 圖示不見了它在 menu bar 不在 Dock. 按住 Command 把它拖到比較左邊的位置
